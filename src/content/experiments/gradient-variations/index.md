## Idea

I made a set of gradient examples to compare how angle, shape, hard stops and layers change a background.

## Notes

1. Linear, radial and conic gradients each spread colors in a different way. The four families make those differences easy to compare.
2. Hard stops create stripes or rings without a color blend.
